## 이어하기 규칙

- 같은 Mac에서 순서대로 작업할 때는 이전 도구의 수정이 끝난 폴더/브랜치를
  다음 도구가 그대로 열 수 있습니다. 미커밋 변경은 먼저 확인하고 보존합니다.
- 동시에 작업할 때는 각자 별도 worktree/브랜치를 사용합니다.
- 진행 중인 작업은 그 작업 브랜치에서 이어받습니다. 아직 병합하지 않은 변경을
  이어받을 때 새로 main만 내려받아 시작하지 않습니다.
- 다른 PC로 옮길 때는 의도한 변경의 커밋·push와 인계 문서 갱신이 필요합니다.
- 비공개 앱의 상세 소스·진행 상태는 해당 비공개 저장소에 기록합니다.

## 도구 관련 결정

- Claude는 승인된 기존 구독 로그인을 사용합니다.
- Google 개인 구독 경로는 Antigravity CLI `agy`입니다. 기존 Gemini CLI 개인
  구독 지원 종료에 대한 공식 전환 안내는 협업 가이드에 연결되어 있습니다.
- 비대화형 명령이 있다는 사실을 읽기 전용 보장의 근거로 삼지 않습니다.
  Antigravity는 헤드리스에서도 활성 작업 폴더 내부 쓰기가 기본 허용됩니다.
- API 키·구독 변경·유료 초과 사용으로 자동 전환하지 않습니다.
- 새 협업 저장소나 중복 PR을 만들지 않고 현재 초안을 이어갑니다.

## 증거와 제한

이번 확인은 GitHub 소스와 공식 CLI 문서에 근거합니다. 현재 실행 환경에는
사용자 Mac 작업 폴더와 CLI 로그인 세션이 연결되어 있지 않습니다. 따라서
'세 AI가 이미 자동으로 함께 실행된다'고 보고할 근거는 아직 없습니다.

이 문서의 목적은 다음 도구가 같은 지점에서 계속하도록 하는 것입니다. 외부
AI 호출과 사용자 기기의 실제 검증이 끝나면 미실행/확인 필요 항목을 실제 결과로
갱신하세요.
