## 무료 배포 준비 · 관리자 수동 단계

1. 기존/신규 Cloudflare 계정의 **Workers Free 및 D1 Free** 확인. 결제수단 입력 또는 유료 전환 화면에서는 중단. 이 작업에서는 계정 생성·원격 DB 변경·배포를 실행하지 않았다.
2. 같은 Worker origin으로 LABDAM과 `/labinsight/`를 제공할 계획 확정. D1 `labdam-membership` 생성 후 wrangler의 placeholder UUID 연결. 원격 migration 전 대상 확인.
3. Google Web OAuth client 생성. `openid email profile`만 사용. 실제 `https://<Worker origin>/auth/callback` 정확히 등록. 앱 게시/조직 제한은 계정에서 확인.
4. `AUTH_ORIGIN`, `GOOGLE_CLIENT_ID` 설정. `GOOGLE_CLIENT_SECRET`, 32자 이상 무작위 `RATE_LIMIT_SECRET`, Gmail/기존 Workspace `BOOTSTRAP_ADMIN_EMAIL`은 대시보드 또는 대화형 secret 입력. 비밀값을 채팅/GitHub에 공유하지 않는다.
5. 보호 번들 빌드 및 테스트 후 `ASSETS.run_worker_first=true` 재확인. OAuth/D1 설정 없는 경우 503으로 닫힌다. 실제 배포는 별도 승인 후 수행한다.
6. 실제 관리자·신청자 계정으로 신청 → 승인 → SSO → 철회 → 기존 세션 차단 → 탈퇴 검증. 관리자 성공 확인 후 bootstrap 이메일 설정 제거. Cron의 정상 실행과 무료 사용량 확인.
7. 아래 공개 경로 정리 계획 승인 및 실행, 익명 HTML/JS/CSS 재검사. Caffeine Atlas URL과 포스터 QR은 유지한다.
8. 실제 모바일의 검사 입력·OCR 검토·PDF 인쇄, Caffeine Atlas 익명 이용 및 물리 포스터 QR 확인. 현재 자동 테스트는 이 실사용 검수를 대신하지 않는다.

Workers의 `run_worker_first=true`는 모든 정적 요청 앞에 Worker를 실행한다. Free 한도 초과 시 Worker 우선 경로는 정적 파일로 우회하지 않고 제한 응답을 받는다. 무료 한도는 Workers 요청/CPU 및 D1 읽기/쓰기/저장량을 각각 확인한다. 유료 전환 명령이나 자동 운영 배포는 추가하지 않았다.
