회원가입 개인정보 처리 안내

이 안내는 LABDAM 및 LabInsight에서 Google 계정으로 가입을 신청하고 관리자 승인을 받는 과정의 개인정보 처리를 설명합니다. 실제 건강검진 입력값과 Caffeine Atlas의 데이터 처리는 별도 정책과 기능에서 다룹니다.

정식 개인정보처리방침 확정 전 안내

운영자 법적 성명(또는 사업자 명칭), 개인정보 보호책임자·비공개 문의처, 회원기록의 구체적인 자동 보유기간 및 Google·Cloudflare의 국외 처리·위탁 관련 사항은 최종 확인이 필요합니다. 확인되지 않은 연락처나 자동 삭제기간을 임의로 표시하지 않습니다. 일반 공개 전 이 항목을 확정해야 합니다.

1. 개인정보처리자 및 문의처

운영 서비스 명칭LABDAM (LabInsight 공통 가입 시스템)
법적 개인정보처리자운영자 실명 또는 공식 사업자 명칭 확인 대기 — 서비스 브랜드명을 법적 명칭으로 대신하지 않습니다.
개인정보 보호책임자·담당 부서운영 책임자 지정·연락처 확인 대기
비공개 개인정보 문의처개설·확인 대기 — 공개 GitHub Issue에 이메일 주소, 신원 증빙, 검사 수치 등을 올리지 마세요.

회원은 내 계정 또는 가입 승인 대기 화면에서 가입 철회 및 계정 삭제를 직접 요청할 수 있습니다. 열람·정정·처리정지 및 별도 민원 접수를 위한 안전한 연락 채널은 정식 공개 전에 안내합니다.

3. 보유기간 및 실제 삭제 시점

아래 기간은 현재 Worker·D1 구현에 근거한 실제 동작입니다. 법정 의무에 따라 별도 보존할 항목이 생기면 사유·기간을 검토하여 변경 안내해야 합니다.

정보 구분현재 보유·삭제 기준
가입 회원정보 및 심사 이력회원의 계정 삭제 요청 시 삭제. 승인 대기·거절·승인 상태 모두 현재 자동 만료·삭제 기능이 없어 계정 삭제 전까지 보관될 수 있습니다. 임의 30일/1년 자동 삭제를 보장하지 않습니다.
일반 로그인 세션발급 후 최대 7일 유효. 로그아웃·탈퇴·관리자 승인 철회 시 서버의 관련 세션을 무효화/삭제. 만료 세션은 매일 정기 정리(정리 지연 시 저장 잔존 가능).
단회 Google OAuth 상태최대 10분 유효. 성공·실패 처리 과정에서 일회성 상태 소비, 만료 상태는 매일 정리.
로그인 횟수 제한용 해시 기록기준 시간 구간에서 24시간을 초과한 기록을 하루 한 번 정리. 정상 정리 기준 실제 저장은 약 48시간까지 이어질 수 있고 장애 시 더 길어질 수 있습니다.
LabInsight / CarePath·가상 예약 체험 기록현재 탭의 sessionStorage에 임시 저장. 사용자 삭제·로그아웃·탈퇴·계정 변경 시 해당 서비스 저장 키 삭제를 시도. 이전 버전의 localStorage 사본도 대상 키에 한하여 정리합니다. 세션 복원·오래된 오프라인 복사본 및 기기에 내려받은 PDF는 별도 정리 필요.

장기간 미처리된 가입 대기·거절 회원정보의 자동 보존 한도는 아직 미설정입니다. 구체적인 삭제 주기를 정하고 실제 서버 정리 코드와 테스트를 적용하기 전에는 자동 파기를 약속하지 않습니다.

4. 정보주체의 권리와 파기 방법

일반 회원은 내 계정·가입 승인 대기 화면에서 직접 탈퇴를 요청할 수 있습니다. 성공 시 회원 행과 연결된 서버 로그인 세션이 삭제됩니다. 관리자는 유일한 관리자 계정 보호를 위해 화면에서 직접 탈퇴할 수 없도록 제한됩니다.

브라우저에 남은 검사·CarePath·가상 예약 체험 기록은 로그아웃·탈퇴·계정 전환 과정에서 해당 저장 키 삭제를 시도하지만 저장소 접근 제한 등으로 실패할 수 있습니다. 이 경우 브라우저의 사이트 데이터를 직접 삭제하세요. 이미 내려받은 문서·스크린샷·PDF는 각 기기에서 별도로 삭제해야 합니다.

회원 계정 삭제 외 개인정보 열람·정정·처리정지 요청에 대한 안전한 접수/본인 확인 절차는 운영자 확인 후 안내 예정입니다. 민원 상담은 개인정보 포털 및 개인정보침해 신고 118도 참고할 수 있으나, 이 채널이 LABDAM 운영자에게 직접 요청을 전달하는 것은 아닙니다.

5. 외부 서비스 및 국외 처리 검토

Google 계정 인증과 Cloudflare Workers·D1 무료 시험 인프라를 사용합니다. 가입 데이터 처리의 계약상 위탁·제3자 제공·국외 이전 여부, 이전 국가·시점·방법·항목·보유기간과 이용자 권리 안내는 실제 계정 설정·계약 조건을 확인한 후 최종 확정해야 합니다. 확인되지 않은 국가나 국외 이전이 전혀 없다는 주장은 하지 않습니다.

별도 공개 서비스인 Caffeine Atlas의 유전자형·선택적 Google Sheets 저장은 이 공통 회원가입 DB와 관계없으며, 기존 공개 링크와 QR은 변경하지 않습니다.

6. 개인정보 보호조치 및 변경 안내

Google 로그인 후 관리자 승인, 세션 무효화, CSRF 검증, 비로그인 정적 자원 접근 차단, 임시 건강정보의 브라우저 내 저장을 사용합니다. 외부 제공사의 접속 로그·백업·운영 보관 기간은 별도 확인이 필요합니다. 안내 내용이 확정 또는 변경되면 게시일과 변경 내용을 함께 공지하겠습니다.
